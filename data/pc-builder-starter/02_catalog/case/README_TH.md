# หมวด case

จำนวน 3,804 รายการ

- parts.json: รายการสินค้าแบบ array เก็บฟิลด์ต้นฉบับทั้งหมด
- parts.jsonl: หนึ่งสินค้าต่อบรรทัด เหมาะกับนำเข้าข้อมูล
- parts.csv: แตกฟิลด์ซ้อนด้วยจุด เช่น metadata.name; ช่อง array เก็บเป็นข้อความ JSON
- จับคู่ด้วย opendb_id; ฟิลด์ที่ไม่มีข้อมูลไม่ใช่การยืนยันว่าเข้ากันได้
- ตัวเลข 0 อาจเป็นค่าเริ่มต้น/ไม่ทราบ ต้องตรวจ schema และผู้ผลิตก่อนตัดสิน
- ห้ามเติมคอมเมนต์ // ใน JSON ให้ใช้เอกสารประกอบนี้
